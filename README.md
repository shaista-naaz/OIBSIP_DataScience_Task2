# Unemployment Analysis

## Objective
The objective of this project is to analyze unemployment data and understand unemployment patterns across different regions and areas, including the impact of COVID-19.

## Steps Performed
1. Loaded the unemployment dataset.
2. Checked the dataset structure, data types, missing values, and duplicate rows.
3. Cleaned the dataset by handling missing Region values and duplicate rows.
4. Converted the date column into datetime format.
5. Analyzed average unemployment rates by region.
6. Compared unemployment rates between rural and urban areas.
7. Analyzed unemployment trends over time.
8. Studied unemployment during the COVID-19 period.
9. Created visualizations and correlation analysis.
10. Identified the highest and lowest unemployment regions and the COVID-19 peak.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Outcome
The analysis identified regional and area-wise unemployment patterns and showed a significant increase in unemployment during the COVID-19 period. The highest average unemployment rate was observed in Tripura, while Meghalaya had the lowest average rate.
